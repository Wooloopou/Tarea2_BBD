Tarea 2 BBD – Avance
Descripción
Avance del proyecto SaludUSM, correspondiente a la implementación de una aplicación web conectada a una base de datos MySQL.
Tecnologías utilizadas
- PHP
- MySQL
- phpMyAdmin
- XAMPP
- HTML/CSS
Avances realizados
Paciente
- Registro de nuevos pacientes.
- Inicio de sesión.
- Agendar citas.
- Reprogramar citas.
- Cancelar citas.
- Consultar citas.
- Consultar historial de atenciones.
- Consultar recetas.
- Modificar datos personales.
- Eliminar cuenta.
Médico
- Inicio de sesión.
- Consulta de agenda.
- Modificación del estado de las citas.
- Registro de atenciones.
- Registro de diagnósticos.
- Registro de recetas.
- Modificación de datos personales.
Administrador
- Gestión de centros médicos.
- Gestión de médicos.
- Gestión de especialidades.
- Asignación de médicos a centros médicos.
- Asignación de especialidades a médicos.
- Creación de usuarios para médicos.
- Modificación de datos personales.
Base de datos
La aplicación utiliza la base de datos SaludUSM, con las tablas correspondientes a pacientes, médicos, citas, atenciones, diagnósticos, recetas, centros médicos, especialidades y usuarios.
Estado actual
La aplicación cuenta con las principales funcionalidades de los tres tipos de usuarios y se encuentra en etapa de avance y pruebas.
